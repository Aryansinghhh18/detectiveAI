# 🕵️ Interactive AI Detective

**Interactive AI Detective** is a Python-based mini-project that simulates an intelligent detective investigation system. The user takes the role of a detective and investigates different cases by examining evidence, interrogating suspects, and exploring connections between clues.

The system uses **classical Artificial Intelligence techniques** rather than machine learning. It represents suspects, clues, locations, alibis, and evidence as a knowledge base and applies logical rules to derive conclusions.

### 🔍 Key Features

* Multiple interactive detective cases
* Evidence and clue investigation
* Suspect interrogation system
* **Breadth First Search (BFS)** for evidence exploration
* **Depth First Search (DFS)** for deep evidence investigation
* Knowledge representation
* Forward-chaining and rule-based reasoning
* AI-generated investigation analysis
* Interactive final accusation system
* Runs directly in **Python IDLE/terminal**
* No website or external database required

### 🧠 AI Concepts Used

The project demonstrates important classical AI concepts such as **state-space search, BFS, DFS, knowledge representation, forward chaining, and rule-based inference**.

The goal of the project is to demonstrate how AI can be used to represent information, explore connected evidence, apply logical rules, and assist in solving an investigation.

**Technology:** Python
**Project Type:** AI Mini Project
